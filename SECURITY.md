# Security Policy

At Lorapok Labs, we take the security of AswitchI very seriously. We appreciate your efforts to responsibly disclose your findings.

## Supported Versions

Currently, the following versions are being actively maintained with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within AswitchI, please do **NOT** open a public issue on GitHub. Instead, please report it privately to our security team.

**How to report:**
1. Email your findings to **lorapokdev@gmail.com**.
2. Include a detailed description of the vulnerability.
3. Provide steps to reproduce the issue (if applicable).
4. If you have a potential patch or mitigation, please include it.

**What to expect:**
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will triage and validate the vulnerability and keep you informed of our progress.
- Once the issue is resolved and a patch is released, we will publicly acknowledge your responsible disclosure (unless you prefer to remain anonymous).

Thank you for helping keep AswitchI and the Lorapok Labs ecosystem safe!
