AswitchI — Guide & Lorapok Labs

🚀 Launching Applications

• Left Click any AI IDE, CLI Agent, or Web AI to launch it immediately with authentic macOS bounce physics.

• Web AIs run directly inside AswitchI with encrypted session persistence (no repeated logins!).

• CLI Agents start in their dedicated terminal session directly in your project workspace.

📂 Workspace Projects

• Right Click any Desktop IDE (Cursor, Kiro, Claude, etc.) to select a workspace project from ~/Shohoz, ~/Desktop, or /mnt/NewVolume/Personal_Projects.

📌 macOS 3D Glass Dock

• Right Click any app in the grid to Pin to Dock or Remove from Dock.

• Pinned apps display real-time live running dots and type badges.

⌨️ Gestures & Keyboard Shortcuts

2-Finger Swipe : Switch Launchpad pages
← / → : Previous / Next page
Esc : Close modal / Back to Launchpad
Enter : Open first search result
